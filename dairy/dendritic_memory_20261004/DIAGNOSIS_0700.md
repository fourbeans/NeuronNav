## 范围与结论等级

本轮只增加诊断工具、只读权重检查和确定性评估复跑；**没有修改 v1 模型、loss、奖励、原 Sigma-D 或原 FMM，也没有重新训练**。
新增工具在 `dendritic_nav/diagnostics/`；所有输出在 `dairy/dendritic_memory_20261004/diagnosis_0700/`。

当前确认的主要问题是：训练后的候选静态残差过强，长期目标频繁跳变；短试训的 target 更新周期与预算不匹配。
这些足以说明不能原样扩成长训练，但尚不能保证修正任何单项就能恢复导航效果。

## 1. 先核对完整结果

100个同身份 episode 配对：Sigma-D Success=57%，加树突=47%；SPL 0.360395→0.349768。
43集两者成功，14集由成功变失败，4集由失败变成功，39集两者失败。

## 2. 已确认的训练日程问题

`train_dend.py` 每1000次 optimizer update才硬同步 target；本轮实际625次，因此同步次数为0。
直接比较 `pilot_final.ckpt.target_state_dict` 与 `initial.ckpt.state_dict`，所有参数/缓冲区的最大绝对差为 **0**。

这不是 target 网络这个方法本身不成立，而是首轮预算和同步周期没有匹配。
在23个代表性训练episode的5048个决策状态中，4980个3决策步TD目标需要 bootstrap，只有68个已覆盖到终止回报。
因此大多数目标依赖整轮未更新的初始空间评分网络，而不是逐渐传播的学习后价值。
**需要缩短同步周期或每次优化做软更新，再用相同预算验证；不能仅凭这一点断言它是全部回退的唯一原因。**

## 3. 残差不再是小修正，且主要来自静态候选分支

使用最终权重，完整重放每个训练actor的第一个episode，共23集，按当前权重从episode起点重建记忆，不使用旧hidden state。
在5048个可决策状态上：

| 诊断量 | 数值 |
|---|---:|
| 选择非空间argmax候选 | 5041/5048 = 99.86% |
| 与空间argmax距离超过0.5m | 4026/5048 = 79.75% |
| 所选目标与空间argmax的平均间距 | 7.66m |
| 该间距的中位数 | 8.31m |
| 候选间总残差平均跨度 | 0.6252 |
| 静态候选项平均跨度 | 0.5329 |
| 记忆交互项平均跨度 | 0.0990 |
| 去掉记忆交互后argmax改变 | 623/5048 = 12.34% |
| 所选候选牺牲的原空间分数均值 | 0.0831 |
| 树突/胞体/读出绝对状态最大值 | 1.5466 |

这是**训练回放状态上的离线诊断，不是导航评估，也不是新增消融训练**。

当前头为：

```text
Δ(c) = w_e·e(c) + w_h·h + w_eh·(e(c)⊙h) + b
```

其中 `w_h·h+b` 对同一步的所有候选相同，在argmax中抵消；因此真正改变排序的是静态项 `w_e·e(c)` 和记忆交互项。
实测静态项跨度明显较大，新模块在很大程度上变成了重写空间选点的静态评分器，而不是预期的历史修正器。
不能把99.86%改点全部解释为树突记忆的影响。

额外诊断：只在输入上去掉候选0的“anchor身份”和“来源”标志，有282个状态恢复选择anchor，远少于5041个改点状态。
因此“仅删掉anchor标志”不足以解释或解决问题，不能凭直觉将它当唯一修复。
